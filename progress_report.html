Integrated Polyakov Gauge (IPG) 在库仑规范格点系综上的实现与验证

报告生成日期: 2026年5月12日

📋 项目概述

项目目标：在已完成库仑规范固定的格点系综基础上，实现积分 Polyakov 规范 (Integrated Polyakov Gauge, IPG) 变换，用于改进格点 QCD 夸克传播子的数值分析。

参考文献：arXiv:1204.0716v2 Appendix A

实现方法：对每个时间切片的时间方向链接进行空间平均，通过 SU(3) 投影和递归构造剩余规范变换，使时间方向链接的空间平均趋于常数矩阵。

🧪 测试内容

1. IPG 定义级验证 (validate_cg_ipg.py)

验证指标：

  • post_spread: IPG 变换后时间链接空间平均的离散度（Z₃ 对齐到目标矩阵 C）
  • boundary: 递归构造 g(t) 的周期闭合误差
  • residual: g(t)u(t)g†(t+1) = C 的最大违反度
  • reconstruct: 写入的 CG+IPG 规范与从原始 CG 规范重建的规范的逐链接最大差异
  • 幺正性和行列式检查: 验证目标矩阵 C、积分 Polyakov 矩阵 P 和变换 g(t) 的 SU(3) 性质

验证容差：

  • --spread-tol = 1e-10
  • --boundary-tol = 1e-10
  • --reconstruct-tol = 1e-10

结果：所有组态通过验证

实际观测到的 IPG 诊断指标通常在 1e-14 到 1e-13 量级，远优于设定的容差要求。

  • 有效质量提取和可视化
  • 原始数据缓存到 artifacts/data/qprop_static_{ensemble}.npz

结果：IPG 后时间方向传播子信号显著改善

  • 测试所有五个 gamma 插入算符：I, gX, gY, gZ, gT

4. 动量空间格林函数测试 (qprop_greens.py)

测试内容：

  • 完全傅立叶变换的夸克格林函数 G_Γ(p) = Nc Tr[Γ S(p)]
  • 选定的 4-动量点（时间动量 n4 = 0..T/2）
  • 所有五个 gamma 插入算符的复数值格林函数
  • 数据缓存到 artifacts/data/qprop_greens_{ensemble}.npz

测试组态：

S16T16_cg S16T16_cg_ipg S32T32_cg_ipg S32T32_cg_ipg_no_hyp S48T64_cg_ipg S48T64_cg_ipg_no_hyp

⚙️ 技术细节

数值方法

  • SU(3) 投影：Cabibbo-Marinari 子群投影，内部容差 1e-14
  • 矩阵 T 次方根：使用 scipy.linalg.logm/expm 计算 P^(1/T)
  • Z₃ 中心对齐：选择使 Frobenius 距离最小的中心相位
  • 行列式归一化：采用主复立方根约定 det^(1/3) = |det|^(1/3) exp(i arg(det)/3)
  • 精度：IPG 构造使用 numpy/scipy complex128（双精度）

夸克求解器

  • 算法：BiCGstab (QUDA 实现)
  • 收敛标准：L2 相对残差 < 1e-8
  • 典型性能：17-19 次迭代收敛，约 250-280 GFLOPS
  • 硬件：NVIDIA GeForce RTX 3060 (sm_86)
  • QUDA 版本：1.1.0

数据管理

  • 输入格式：NERSC 规范场文件
  • 输出格式：NERSC 规范场文件 (CG+IPG) + NumPy 归档 (变换 g(t))
  • 缓存：传播子和格林函数数据缓存为 .npz 格式
  • 可视化：所有图表保存为 PDF 格式
