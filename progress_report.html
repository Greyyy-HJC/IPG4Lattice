📋 Project Overview

Project Goal: Implement the Integrated Polyakov Gauge (IPG) transformation on Coulomb-gauge-fixed lattice ensembles to improve numerical analyses of lattice QCD quark propagators.

Reference: arXiv:1204.0716v2 Appendix A

Implementation Approach: Spatially average the temporal links on each time slice, then use SU(3) projection and a recursive residual gauge transformation so that the spatial average of the temporal links approaches a constant matrix.

🧪 Test Content

1. IPG Definition-Level Validation (validate_cg_ipg.py)

Validation Metrics:

  • post_spread: Dispersion of the spatially averaged temporal links after IPG transformation, with Z₃ alignment to the target matrix C
  • boundary: Periodic closure error of the recursively constructed g(t)
  • residual: Maximum violation of g(t)u(t)g†(t+1) = C
  • reconstruct: Maximum link-by-link difference between the written CG+IPG gauge and the gauge reconstructed from the original CG gauge
  • Unitarity and determinant checks: Validate the SU(3) properties of the target matrix C, the integrated Polyakov matrix P, and the transformation g(t)

Validation Tolerances:

  • --spread-tol = 1e-10
  • --boundary-tol = 1e-10
  • --reconstruct-tol = 1e-10

Result:All ensembles passed validation

The observed IPG diagnostic metrics are typically in the 1e-14 to 1e-13 range, well below the configured tolerances.

2. Static Quark Propagator Test (qprop_static.py)

Test Content:

  • Wall-source temporal propagator with spatial averaging
  • Point-source spatial propagator starting from the origin
  • Effective-mass extraction and visualization
  • Raw data cached to artifacts/data/qprop_static_{ensemble}.npz

Result:The temporal propagator signal improves significantly after IPG

3. Momentum-Projected Propagator Test (qprop_mom.py)

Test Content:

  • Momentum-wall-source temporal propagator
  • For each momentum p, use wall-source × exp(±ip·x) phases, improving statistics by a factor of L³ compared with a single point source
  • Test all five gamma insertions: I, gX, gY, gZ, and gT
  • Effective-mass visualization for each momentum

Test Ensembles:

S16T16_cg_ipg S32T32_cg_ipg S32T32_cg_ipg_no_hyp S48T64_cg_ipg S48T64_cg_ipg_hyp

Gamma Operators:

Result:Momentum-projected propagators show good signals across the tested momentum points

4. Momentum-Space Green's Function Test (qprop_greens.py)

Test Content:

  • Fully Fourier-transformed quark Green's function G_Γ(p) = Nc Tr[Γ S(p)]
  • Selected four-momentum points with temporal momentum n4 = 0..T/2
  • Complex-valued Green's functions for all five gamma insertions
  • Data cached to artifacts/data/qprop_greens_{ensemble}.npz

Test Ensembles:

S16T16_cg S16T16_cg_ipg S32T32_cg_ipg S32T32_cg_ipg_no_hyp S48T64_cg_ipg S48T64_cg_ipg_no_hyp

Gamma Operators:

I gX gY gZ gT pDotg

Result:Green's functions show the expected Dirac structure

The trace of G_Γ(p) encodes the inverse-propagator dressing functions A_s, A_t, and B_m (reference Eq. 20), which should be approximately independent of p4.

⚙️ Technical Details

Numerical Methods

  • SU(3) Projection: Cabibbo-Marinari subgroup projection with an internal tolerance of 1e-14
  • Matrix T-th Root: Compute P^(1/T) with scipy.linalg.logm/expm
  • Z₃ Center Alignment: Select the center phase that minimizes the Frobenius distance
  • Determinant Normalization: Use the principal complex cube-root convention det^(1/3) = |det|^(1/3) exp(i arg(det)/3)
  • Precision: IPG construction uses numpy/scipy complex128 double precision

Quark Solver

  • Algorithm: BiCGstab (QUDA implementation)
  • Convergence Criterion: L2 relative residual < 1e-8
  • Typical Performance: Converges in 17-19 iterations at approximately 250-280 GFLOPS
  • Hardware: NVIDIA GeForce RTX 3060 (sm_86)
  • QUDA Version: 1.1.0

Data Management

  • Input Format: NERSC gauge-field files
  • Output Format: NERSC gauge-field files (CG+IPG) plus NumPy archives for the transformation g(t)
  • Caching: Propagator and Green's function data are cached in .npz format
  • Visualization: All plots are saved in PDF format
